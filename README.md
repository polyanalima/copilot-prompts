# Copilot Prompts - Agentes de Carreira em Tecnologia

Este projeto faz parte do Bootcamp DIO e contém dois agentes (prompts) criados para auxiliar pessoas interessadas em tecnologia a descobrirem e planejarem suas carreiras.

## 📌 Agentes incluídos

### Agent 1 - Entrevistador de Carreira em Tecnologia
- Conduz uma entrevista estruturada de 7 perguntas.
- Identifica interesses, motivações, experiência prévia e objetivos profissionais.
- Sugere 3 carreiras ranqueadas com base no perfil.
- Transfere as informações para o Agent 2.

### Agent 2 - Planejador de Carreira
- Recebe os dados do Agent 1 (carreira escolhida, horas semanais, experiência, objetivo, preferências e interesses).
- Gera um plano completo de estudos com:
  - Visão do dia a dia da carreira
  - Mapa de skills essenciais e complementares
  - Roadmap de 90 dias adaptado à disponibilidade
  - Projeto de portfólio
  - Roteiro de entrevistas
  - Trilha DIO recomendada

## 🎯 Objetivo
Fornecer prompts prontos para uso que apoiem estudantes e profissionais na evolução de suas carreiras em tecnologia, desde a escolha da área até o planejamento de estudos.
